# TYRIAN 2000: PROGRAM ZERO - MASTER CAMPAIGN SCRIPT
# מדריך עריכת תסריט המשחק (עברית)
# קובץ זה מרכז את כל הדיאלוגים, התדריכים, מטרות המשימה והודעות הקשר לכל 100 השלבים.
# ניתן לערוך את הטקסטים חופשי, ולאחר מכן להחזיר אליי את הקובץ המעודכן לעדכון אוטומטי במשחק.

================================================================================
הוראות מבנה קובץ העריכה:
1. בכל שלב מופיעים: מספר השלב, שם המבצע, המיקום, סוג המשימה והמטרה הראשית.
2. רצף הדיאלוגים (MISSION COMMS) מופיע שורה אחר שורה עם ציון שם הדובר (אלנה, נעמי, גוסט, סרה).
3. הודעות הקשר בזמן אמת (IN-MISSION COMMS) מוצגות בנפרד למקרה של הפתעות או מארבים.
4. סצנות סיום פרק (AFTER-ACTION) מופיעות בסוף כל עשירייה (שלבים 10, 20, 30 וכו').
================================================================================
