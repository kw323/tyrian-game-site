# מרכז הפיקוד החדש — אוגוסט 2026

מרכז הפיקוד החדש מחליף את מסך הכניסה העמוס במבנה קלאסי וברור: סרגל ניווט קבוע בצד שמאל ותוכן גדול בצד ימין. הסגנון נשאר חללי ומבוסס על פלטת הכחול־שחור, ציאן, ירוק וענבר של המשחק, אך הפעולות הראשיות גדולות יותר והמידע מחולק לקטגוריות קבועות.

| קטגוריה | תפקיד |
|---|---|
| Game | התחלת קמפיין, המשך שמירה ומפת שלבי בדיקה |
| Upgrades | גישה למודיעין מערכות החללית ולהגדרות שליטה |
| Save / Load | ניהול שמירות ידניות ושמירה אוטומטית |
| Settings | תצוגה, מוזיקה, שפה, רמת קושי ומיפוי שליטה |
| Intel | מאגר אויבים, ארכיון משימות ומערכות חללית |
| Exit | יציאה עם מסך אישור מפורש |

## שמירות מדופדפות

מערכת השמירות מציגה **10 חריצים גדולים בעמוד**, בדו־טור, ומאפשרת מספר בלתי מוגבל של עמודים. החריצים ההיסטוריים 1–3 נשארו באותו מפתח localStorage ולכן נשמרים באופן מלא בעמוד הראשון. השמירה האוטומטית נשארת נפרדת בתחילת מסך הטעינה.

| פעולה | עכבר | מקלדת |
|---|---|---|
| בחירת חריץ | לחיצה על הכרטיס | חצים או `WASD` |
| טעינה/שמירה | לחיצה על הכרטיס | `Enter` או `Space` |
| דפדוף עמודים | Previous / Next | `Q` / `E` או `PageUp` / `PageDown` |
| מחיקה | Delete בכרטיס מאוכלס | `Delete` / `Backspace`, ואז `Enter` לאישור |
| חזרה | Close | `Esc` |

## קיצורים במרכז הפיקוד

`1`–`6` בוחרים את אחת משש הקטגוריות כאשר אין פקד אחר במיקוד. `↑`/`↓` או `W`/`S` עוברים בין קטגוריות, ו־`Enter` מפעיל את הפעולה הראשית של הקטגוריה. לחצנים עצמם ממשיכים לעבוד באופן מקורי עם Tab, Enter ו־Space. מסכי חלון כגון שמירה, ארכיון או הגדרות שליטה מקבלים עדיפות על קיצורי המרכז.
