# סטטוס גרסת המחשב — אוגוסט 2026

גרסת המחשב של **Protect The Starship** היא קו הפיתוח הפעיל של המאגר. היא נבנית באמצעות Vite ו־Electron ומיועדת להפצה לא־מקוונת כקובץ Windows נייד. מסך הכניסה, שמירות מקומיות, תדריכי שלב, שליטת מקלדת ועכבר, והקמפיין המלא נשארים חלק מהיעד הפעיל.

| תחום | מצב נוכחי | מקור עיקרי |
|---|---|---|
| הפעלה בדפדפן | פעיל | `pnpm dev` |
| בדיקת טיפוסים | פעיל | `pnpm check` |
| בדיקות לוגיקה | פעיל | `pnpm exec vitest run` |
| בניית הפצה | פעיל | `pnpm build` |
| הפצת Windows | פעיל | `pnpm electron:pack` |
| Android | מושהה | `android/` ו־`capacitor.config.ts` נשמרים להמשך עתידי |

## מה נשמר בגרסת המחשב

קמפיין 101 השלבים, תדריכי קדם־שלב, מסך הכניסה והטעינה, מיפוי מקשים, שליטת עכבר, עיצוב ששת הנשקים, מערכת הריאקטור, סגנונות האויבים, הבוסים, סרה, Archon, הסיום והקרדיטים נשמרים בענף `main`. מסמכי התכנון המתאימים נמצאים בתיקיית `docs/`.

## מדיניות Android

פיתוח Android אינו נמחק מההיסטוריה ואינו מושלך, אך הוא אינו יעד לבדיקות, שינויים או הפצה עד שהמשתמש יבקש לחדש אותו. הדבר מאפשר להתמקד באיכות גרסת Windows בלי לאבד את תשתית Capacitor או את הידע שנצבר.

## סדר עבודה מומלץ מעתה

כל שינוי משחקי חדש יבוצע תחילה בגרסת הדפדפן והמחשב, יעבור `pnpm check`, בדיקות Vitest ובניית `pnpm build`, ורק לאחר מכן — אם נדרש — תיבנה חבילת Windows. לפני עבודה עתידית על דיבוב יש לעיין ב־[`voice-assets-status-2026-08.md`](voice-assets-status-2026-08.md).
