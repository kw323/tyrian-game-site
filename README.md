# Protect The Starship

**Protect The Starship** הוא משחק יריות חלל דו־ממדי המבוסס על React, TypeScript ו־HTML5 Canvas. גרסת המחשב היא יעד הפיתוח הפעיל של הפרויקט: קמפיין בן 101 שלבים, שדרוגי חללית, תדריכי סיפור, שמירות מקומיות והפצת Windows לא־מקוונת.

> סטטוס פלטפורמה: **Desktop / Windows הוא היעד הפעיל.** עבודת Android נשמרת במאגר אך מושהית ואינה חלק ממסלול הפיתוח או הבדיקה הנוכחי.

## הפעלה ובנייה

| מטרה | פקודה | תוצר |
|---|---|---|
| פיתוח מקומי | `pnpm dev` | כתובת Vite מקומית |
| בדיקת טיפוסים | `pnpm check` | אימות TypeScript ללא יצירת קבצים |
| בדיקות משחק | `pnpm exec vitest run` | בדיקות מערכות המשחק |
| בדיקת נכסי דיבוב | `pnpm voice:verify` | אימות 331 קובצי הדיבוב הפעילים |
| בניית דפדפן / שרת | `pnpm build` | `dist/` |
| חבילת Windows ניידת | `pnpm electron:pack` | קובץ `.exe` תחת `dist/` |

## תוכן הקמפיין

הקמפיין כולל שלושה צבאות בעלי סגנונות תנועה וירי שונים, שישה סוגי נשק עם 25 דרגות לכל אחד, ריאקטור אנרגיה עם מצב התאוששות, בוסים בעלי שלושה ארכיטיפים, סרה כבעלת ברית בשלבים 81–90, וסיום Archon עם מצב Meltdown. מסך הכניסה מאפשר התחלת משימה חדשה, המשך משמירה, ניהול שלוש שמירות ידניות, שמירה אוטומטית והגדרות שליטה.

תדריכי השלב והדיאלוגים מציגים טקסט רב־לשוני. קבצי הקול ומצב הכיסוי שלהם מתועדים ב־[`docs/voice-assets-status-2026-08.md`](docs/voice-assets-status-2026-08.md); כל 331 מזהי הדיבוב הפעילים מצביעים כעת על קובצי MP3 תקינים, וניתן לאמת זאת באמצעות `pnpm voice:verify`.

## מפת המאגר

| מיקום | ייעוד |
|---|---|
| `client/src/game/` | מערכות משחק, ישויות, קמפיין, דיאלוגים ושמירות |
| `client/src/components/` | מעטפות React, הקנבס, חלונות שמירה והגדרות |
| `client/public/voices/` | קובצי קול מקומיים ותמלילים |
| `electron/` | תהליך Electron ואריזת Windows הלא־מקוונת |
| `docs/` | מסמכי עיצוב, מצב נכסים ותיעוד תחזוקה |
| `scripts/` וכלי השורש | כלי עזר היסטוריים לעיבוד קמפיין, דיאלוגים וקול; אינם מופעלים בזמן ריצה |
